💰 Mudabbir Dashboard
Madabber is an Arabic financial dashboard that helps you manage your money smartly.
It features a modern sidebar and main dashboard displaying budgets, invoices, recent activities, and income vs. expenses summaries.

📖 Overview

Madabber provides a professional, RTL (Right-to-Left) user interface for personal financial management, including:
• A responsive sidebar for easy navigation.
• Account and transaction summaries.
• Monthly bills and expense tracking.
• Visual income vs. expense analysis.
• Full Arabic language support.

⸻

🌟 Features

✅ Modern, elegant design using advanced CSS styling and box shadows.
✅ Interactive interface with Font Awesome icons.
✅ Beautiful typography with IBM Plex Sans Arabic from Google Fonts.
✅ Well-organized structure with utility-based CSS classes.
✅ Responsive grid layout for clean and consistent visuals.

🖋️ Technologies Used

Technology Purpose
HTML5 Building the page structure
CSS3 Styling and layout
Font Awesome Adding meaningful icons
Google Fonts Using IBM Plex Sans Arabic font
Flexbox / CSS Grid Creating responsive layouts
RTL Layout Full Arabic right-to-left support

🧱 Main Components

🗂️ Sidebar

Includes:
• Logo and main title
• Navigation links
• Quick action buttons like Send Money, Add Funds, Pay Bill, and Invest

💵 Financial Cards

Display summary data such as income, expenses, current balance, and monthly bills.

📊 Income vs Expenses Chart

Visual comparison of weekly or monthly income vs. expenses using color-coded bars.

📋 Recent Transactions

A neatly formatted list showing recent activities with icons and user avatars.

🪄 Additional Notes
